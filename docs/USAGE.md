# Bambu Monitor 使用指南

从零开始，大约 **10 分钟**：打印机开两下开关 → 装固件 → 输两行配对信息 → 完成。

```
第一步 打印机准备（3 分钟）
第二步 安装固件（2 分钟）
第三步 首次配对（1 分钟）
完成 ✅ 日常使用 / 遇到问题看「排查」
```

---

## 第一步：在打印机上开启局域网访问

监视屏通过**局域网**直连打印机，需要在打印机上拿到两样东西：**IP 地址** 和 **访问码**。

以拓竹 H2D 为例（其他型号菜单名略有差异，找「局域网 / LAN」相关页面即可）：

1. 在**打印机屏幕**上：`设置` → `网络`（或 `WLAN`）→ 找到**局域网模式**页面。
2. 确认**开发者模式 / 局域网服务**处于开启状态（H2D 新固件默认允许局域网集成；老固件需要手动开）。
3. 抄下页面上显示的两个值：
   - **IP 地址**：形如 `192.168.31.174`
   - **访问码**：8 位字符，形如 `4af8d8f6`（旁边有一个刷新按钮，点它会换新码）

> ⚠️ **关于「仅局域网模式」开关，最重要的一条：**
>
> 这个开关**每切换一次，访问码就会重置一次**。
>
> - 开关**关闭**（推荐）：手机 Bambu Handy 正常使用，监视屏也能连 —— 两边都好；
> - 开关**开启**：手机端将连不上打印机（云端被切断），只剩局域网设备可用。
>
> 无论开关状态如何，页面上的访问码都能看到、监视屏都能连。**推荐保持关闭**。
> 如果你以前切换过这个开关，请以屏幕上**当前显示**的访问码为准。

## 第二步：安装监视屏固件

两种方式任选：

**方式 A：下载现成固件（推荐）**

1. 到本仓库 [Releases](../../releases)（或 Mosaico Ideas 项目页）下载 `bambu_monitor-v0.2-system-update.irisfw`。
2. 用 USB 线连接 Mosaico 设备，在 ESP-Mosaico 工作台的 **System Update** 页面上传安装；或在 workspace 里执行：
   ```sh
   python mosaico.py iris system-update --bundle bambu_monitor-v0.2-system-update.irisfw
   ```
3. 安装完成后设备自动重启进入监视屏。

**方式 B：源码构建**

本项目属于 ESP-Mosaico workspace 的一个应用，在 workspace 根目录：

```sh
python mosaico.py iris system-update --project projects/bambu_monitor
```

依赖与构建环境见根 [README](../README.md#方式二源码构建)。

## 第三步：首次配对

监视屏第一次启动会显示「连接中」——因为还不知道你的打印机在哪。

1. 点右下角 **设置** 按钮。
2. 点 **IP** 那一行进入键盘：
   - 输入第一步抄下的打印机 IP（只允许数字和小数点，格式错了会提示「IP 无效」）；
   - 按 **确定** 返回。
3. 点 **访问码** 那一行进入键盘：
   - **先按一下「清空」**（避免残留旧字符）；
   - 逐位输入 8 位访问码。输入框是大字号显示，每一位都能看清；
   - 按 **确定**，再按 **保存**。
4. 保存后状态栏显示「已保存，正在连接…」，几秒内左上角从「连接中」变成「**在线**」即成功。

> 💡 输码小技巧：数字 `8` 和字母 `b` 在键盘相邻两行，最容易按混。输完盯着大字输入框核对一遍再按确定。
> 配对信息存在设备里，**断电不丢**，之后开机自动连接。

## 日常使用

### 状态页（开机默认）

| 位置 | 内容 |
| --- | --- |
| 顶部 | 连接状态 + 打印机型号；右上「重连」「设置」 |
| 中部大卡 | 打印状态 + 百分比大字 + 进度条 |
| 任务卡 | 任务文件名、当前层/总层数、**剩余时间**和**预计完成时刻** |
| 温度卡 | 喷嘴 / 热床的目标与实时温度（腔体温度取决于打印机上报） |
| 底部 | 空闲时显示「打印控制」「料仓」；**打印中**变为四个快捷键 |

### 打印中的快捷操作

打印时底部出现：**暂停（继续）· 灯 开/关 · 料仓 · 控制**

- **暂停 / 继续**：直接切换，打印机确认后按钮状态更新。
- **灯**：开关打印机腔室照明。
- **料仓**：查看 AMS 每个槽位的颜色色块、材质名（PLA / PETG / PLA-AERO…）、余量百分比，以及湿度、温度。
- **控制页**：三档速度（静音/标准/运动）、腔室灯、**停止**。

### 停止打印（防误触设计）

1. 按「停止打印」→ 按钮变成「**再按一次确认停止**」；
2. **5 秒内**再按一次才真正停止；离开页面或超时自动取消。
3. 确认与当前任务绑定：如果期间打印机换了任务，确认会自动作废，不会误停新任务。

### 完成 / 出错提醒

- 打印**完成**：全屏弹窗「打印完成 · 可以取件了」+ 蜂鸣一声。
- 打印**出错**：全屏弹窗显示完整 32 位错误码（如 `0x08000001`）+ 蜂鸣。
- 按「好的」关闭弹窗回到状态页。
- 重连或换任务后，旧的未确认提醒自动作废，不会误关新提醒。

## 连不上？按顺序排查

监视屏显示「打印机离线 · 重连中…」时，90% 是下面第一条：

1. **访问码变了**（最常见）：去打印机屏幕看当前访问码，和监视屏里存的是否一致——只要切换过「仅局域网模式」开关，码就重置了。进监视屏 **设置 → 访问码 → 清空 → 重输** → 保存。
2. **IP 变了**：打印机重启后 DHCP 可能分配新地址（一般不变）。在打印机屏幕确认 IP，必要时在监视屏更新。
3. **开发者模式 / 局域网服务被关了**：回打印机屏幕打开。
4. **不在同一网段**：确认打印机和 Mosaico 设备连的是同一个路由器。
5. 以上都没问题 → 点监视屏右上 **重连** 按钮手动重连一次。

## 常见问题

**手机 Bambu Handy 和监视屏冲突吗？**
不冲突。两者同时连没问题。唯一的坑是「仅局域网模式」开关：开着它手机端连不上（见第一步的警告）。

**断电重启后需要重新配对吗？**
不需要，配对存在设备 NVS 里。

**监视屏半夜自己黑屏/关机了？**
如果它插在**电脑的 USB 口**上，电脑关机或睡眠会切断 USB 供电，设备随之断电——这不影响打印机，打印任务照常进行。**日常使用请用独立的 USB 电源适配器（任意 5V/1A 充电头）供电**，USB 线接电脑只用于安装固件和调试；否则电脑一关，过夜打印的完成/出错提醒就收不到了。

**支持哪些打印机 / 料仓？**
已在 **H2D + AMS Pro** 实测。P1 / A1 / X1 系列未验证（协议相近但不保证，欢迎反馈）。

**连接安全吗？**
局域网内 TLS 加密传输。当前实现跳过了打印机自签名证书的校验（无法离线预置），请仅在**家庭内网**使用。

**为什么按暂停后要等一两秒才生效？**
命令在收到打印机的下一份状态报文时才发出（实测约 1.3 秒一帧），之后还要等打印机确认。这是有意设计，避免发出过时的命令。

**腔体温度一直显示「--」？**
H2D 的状态报文暂不包含腔体温度字段，属正常现象。
